# Manuscript sources

Latest manuscript version (Elsevier EAAI submission) of *Data-driven machine learning
surrogate model for the S175 ship performance prediction*.

- `main.tex` — manuscript (elsarticle); `sample.bib` — references (64 entries, all cited).
- `*.pdf` — the ten figures the manuscript includes, flat next to `main.tex` so the folder
  compiles as is (Overleaf: upload the whole folder). Eight are generated by the scripts
  in `../scripts/` (copies of `../figures/`); `s175_Dataset-Gen.pdf` and
  `S175ML-V5-F.drawio-updated-22-08-2026.drawio.pdf` are hand-drawn diagrams.
- Tables are generated into `../results/evaluation/latex/` (git-ignored) by
  `../scripts/18_paper_tables_clean.py` and `../scripts/23_alpha_grid_table.py`.

Check the manuscript against the committed results:

    python scripts/verify_tables.py      # every table cell vs the generated tables
    python scripts/verify_manuscript.py  # traceable numbers in the text + figure files
